# Swamp Needle - Deployment Instructions

## 📦 Files You Need

Upload these 2 files to deploy your site:

1. **index.html** (the website)
2. **swamp-needle-hero.png** (your bar image)

Both files are in the outputs folder.

---

## 🚀 Deployment Options

### OPTION 1: Vercel Direct Upload (Easiest - 2 minutes)

1. Go to **[vercel.com](https://vercel.com)**
2. Sign up/login (use GitHub, Google, or email)
3. Click **"Add New"** → **"Project"**
4. Click **"Deploy without Git Repository"**
5. Drag and drop both files:
   - `index.html`
   - `swamp-needle-hero.png`
6. Click **"Deploy"**
7. ✅ Done! Your site is live

**Your URL will be:** `your-project-name.vercel.app`

---

### OPTION 2: GitHub + Vercel (Best for future updates)

#### Step 1: Upload to GitHub
1. Go to **[github.com](https://github.com/new)**
2. Create new repository named `swamp-needle`
3. Click **"uploading an existing file"**
4. Drag both files:
   - `index.html`
   - `swamp-needle-hero.png`
5. Click **"Commit changes"**

#### Step 2: Deploy on Vercel
1. Go to **[vercel.com](https://vercel.com)**
2. Click **"Add New"** → **"Project"**
3. Click **"Import Git Repository"**
4. Select **`swamp-needle`** repo
5. Leave all settings default
6. Click **"Deploy"**
7. ✅ Done! Site is live

**Benefit:** Future updates = just edit files on GitHub, auto-deploys

## 🌐 Custom Domain Setup

### After Deployment:

1. In Vercel, go to your project
2. Click **"Settings"** → **"Domains"**
3. Add your domain (e.g., `swampneedle.com`)
4. Follow Vercel's instructions to update DNS

### Where to Buy Domain:
- **Namecheap** (recommended, ~$10/year)
- **Google Domains** (~$12/year)
- **Cloudflare** (~$10/year)

Popular domain ideas:
- swampneedle.com
- swampneedlenola.com
- swampneedle.bar

## 🔧 Troubleshooting

### "Image not showing"
- Make sure `swamp-needle-hero.png` is in the same folder as `index.html`
- Check file name is exactly: `swamp-needle-hero.png` (case-sensitive)

### "Site not updating"
- Vercel may cache for a few minutes
- In Vercel dashboard, click **"Redeploy"**
- Or clear browser cache (Ctrl+Shift+R / Cmd+Shift+R)

### "Custom domain not working"
- DNS changes take 24-48 hours
- Check Vercel's domain instructions
- Make sure nameservers are updated
